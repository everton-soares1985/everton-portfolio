# Agent guidance

- Keep changes scoped to the user request and preserve existing uncommitted work.
- The public catalog is curated; private systems are not automatic publication sources.
- Do not invent metrics, credentials, employment, book notes or client testimonials.
- Keep PT/EN, both themes, accessibility and mobile layouts functional.
- Never commit .env files, secrets, private keys, logs, databases or artifacts/.
- Keep legacy AI disabled. No deployment or external writes without authorization.
- Use existing modules and Lucide icons. Avoid redundant frameworks or dependencies.
- Run npm test; validate UI changes with tests/browser.mjs against the local preview.
- Use GrowthTech GitHub Publisher check before publishing; document tool limitations.
