# Contributing

Discuss proposed changes with the owner before starting substantial work.
Preserve both languages, both themes and narrow mobile layouts.
Do not fabricate qualifications, project results or personal history.

Use Node.js 22 or newer. Run npm test and, with an available Playwright installation
and Microsoft Edge, node tests/browser.mjs. PLAYWRIGHT_MODULE may point to an existing
Playwright installation. Keep the preview running on 127.0.0.1:4317 during UI tests.

Never include credentials or local artifacts. Do not enable AI, deploy hosting or
change the visual identity as part of unrelated maintenance.
