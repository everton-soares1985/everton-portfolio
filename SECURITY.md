# Security

This portfolio displays an intentionally selected public catalog. Never commit
environment files, provider credentials, private keys, databases or personal exports.
Only files under public/ belong in a static hosting document root.

The legacy AI endpoint is disabled by default. Keep it disabled for this version.
The terminal is a local navigation interface, not a command execution service.

Report vulnerabilities privately to Everton Soares through the LinkedIn contact
linked in the portfolio. Do not open issues containing credentials or private data.
For accidental credential exposure, revoke the credential before discussing details.
